# 👑 RoyalStay Hotel & Resort

**Experience Comfort, Elegance & Luxury.**

A modern, responsive, and user-friendly hotel booking web application built with React and Tailwind CSS. RoyalStay provides guests with a seamless experience for exploring hotel rooms, making reservations, managing their accounts, and tracking their bookings.

---

## 📌 Project Overview

RoyalStay is a frontend hotel management and reservation application designed to simplify the hotel booking experience. Guests can explore different room categories, view detailed room information, check room capacity and pricing, and make reservations through an intuitive interface.

The application also includes user authentication, profile management, booking history, and hotel services, creating a complete hotel reservation experience.

## ✨ Features

- **Room Exploration** – Browse available rooms and explore different categories.
- **Room Details** – View room descriptions, images, amenities, pricing, and capacity.
- **Room Search & Filtering** – Find rooms based on search criteria and preferences.
- **User Authentication** – Register, log in, and log out.
- **Booking Management** – Make reservations and store booking information.
- **My Bookings** – View and manage personal reservations.
- **User Profile** – View and update personal account information.
- **Hotel Services** – Explore available hotel services.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd RoyalStay
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit the local URL provided by Vite, usually:

```text
http://localhost:5173
```
